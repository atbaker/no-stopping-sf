## Web research preference

- For open-web research, use Exa's `web_search_exa` before Codex's built-in web search.
- Use Exa's `web_fetch_exa` when full page content is needed.
- Fall back to built-in web search only when Exa is unavailable, fails, lacks the required capability, or higher-priority instructions require another source.
- Continue to prefer purpose-built connectors and authoritative documentation tools when applicable.
